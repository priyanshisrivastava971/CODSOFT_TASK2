## Advanced Tic Tac Toe AI Game Using Python

### Project Description
This project is developed as part of the CodSoft Python Programming Internship.

It is an interactive Tic Tac Toe game where a human player competes against an intelligent AI opponent.

### Features
- Interactive 3×3 Tic Tac Toe board
- Human vs AI gameplay
- Minimax algorithm
- Multiple difficulty levels
- Scoreboard
- Reset and replay option
- Win, lose and draw detection

### Technologies Used
- Python
- Google Colab
- Jupyter Notebook
- Minimax Algorithm

### How to Run
1. Open the CODSOFT_TASK2.ipynb notebook.
2. Run all cells.
3. Select your difficulty level.
4. Start playing!
